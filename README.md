#Nadeau Fuel cards and Transaction SQL Server

#Basics
Starting from a boot.dev project I am working on, this will be a fileserver that will serve internal web pages built in HTML, These pages will allow users to view data in the MSSQL DB in a way that makes sens to them, they will also be able to update/add to them in a user friendly way.
Finance department will use this to query for transaction list, simplify the IFTA process, reporting and billing.
